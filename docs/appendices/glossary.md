# Glossary

Purpose: Comprehensive definitions of technical terms, concepts, and acronyms used throughout the Agent Audiobook Maker project.

This glossary provides clear definitions for specialized terminology used in documentation, code, and project discussions.

## Core Concepts

Agent Audiobook Maker (ABM): The system for converting text content into structured annotations and audio.

Annotation Pipeline: Multi-stage process generating dialogue/narration metadata.

Narration: Non-dialogue text content.

Pipeline: Sequence of processing stages.

Quality Gate: Validation checkpoint.

Segmentation: Breaking text into units.

Speaker Attribution: Identifying the speaker for utterances.

Text-to-Speech (TTS): Tech converting text to spoken audio.

Utterance: Single unit of speech/text.
